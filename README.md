# 🎮 Tic Tac Toe (4×4)

A modern and interactive **4×4 Tic Tac Toe** game built using **HTML, Tailwind CSS, and Vanilla JavaScript**.  
Play with a friend locally or challenge an AI with multiple difficulty levels.  
The first player to **win 5 rounds** becomes the champion 🏆.

---

## ✨ Features

- 🎯 4×4 Tic Tac Toe board (extended gameplay)
- 👥 **2 Player (Local Multiplayer)** mode
- 🤖 **Play vs AI** with 3 difficulty levels:
  - Easy – Random moves
  - Medium – Smart blocking & tactics
  - Hard – Minimax algorithm (depth-based)
- 📊 Live scoreboard (First to 5 wins)
- 🎨 Modern UI with Tailwind CSS
- 📱 Mobile-friendly & responsive design
- 🔔 Smooth animations & vibration feedback (supported devices)

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (Vanilla)**
